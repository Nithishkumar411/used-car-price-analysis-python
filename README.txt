PROJECT DESCRIPTION:
This project analyzes used car data using Python to understand how car prices relate to manufacturer, fuel type, transmission, vehicle age, and kilometres driven.

FILES INCLUDED:
1. Used_Car_Price_Analysis_Report.pdf — Project report.
2. used_car_price_analysis.ipynb — Python code and data analysis.
3. car_details_v4.csv — Dataset used for analysis.

TOOLS USED:
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

HOW TO RUN:
1. Open Google Colab.
2. Upload the IPYNB notebook.
3. Upload the CSV dataset when requested by the notebook.
4. Run the notebook cells in order to view the analysis and charts.
